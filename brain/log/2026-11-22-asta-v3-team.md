# 2026-11-22 — Asta v3 Takım Çalışması: Araştırma, Kararlar ve P0

**Tarih:** 2026-11-22  
**Faz:** Asta v3 üretim iyileştirmeleri (Faz 6.6 sonrası)  
**Durum:** Devam Ediyor

---

## Amaç

Asta v3 üretiminde ölçülen darboğazları araştırıp karara bağlamak, P0 streaming encode'un bellek davranışını ölçmek ve uygulama dalgalarını planlamak. Kapsam araştırma, karar ve P0 ölçümüdür; özelliklerin tamamlanması ayrı dalgalara bırakılmıştır.

---

## Yapılanlar

1. **Araştırma aşaması — 11 rapor tamamlandı.** Raporların tamamı kaynak kodu okumasına dayanır ve `status: draft` taşır:
   - Render/CLI: [render-range](../research/2026-11-22-render-range.md), [render-progress-eta](../research/2026-11-22-render-progress-eta.md), [probe-sheet-multiframe](../research/2026-11-22-probe-sheet-multiframe.md), [cli-help-discovery](../research/2026-11-22-cli-help-discovery.md).
   - Şema/medya: [audio-fade-gain-automation](../research/2026-11-22-audio-fade-gain-automation.md), [smart-reframe-916](../research/2026-11-22-smart-reframe-916.md), [particle-burst-binding](../research/2026-11-22-particle-burst-binding.md).
   - Görsel/QC: [ribbon-color-thickness](../research/2026-11-22-ribbon-color-thickness.md), [text-scrim-backplate](../research/2026-11-22-text-scrim-backplate.md), [material-swatch-gallery](../research/2026-11-22-material-swatch-gallery.md).
   - Kurgu: [autocut](../research/2026-11-22-autocut.md).
   - Girdi: [asta-v3-uretken-darbogazlari](../research/2026-11-22-asta-v3-uretken-darbogazlari.md).
2. **ADR-0004 kabul edildi.** [Şema Sürümünde Minor Geriye Uyumluluğu](../decisions/0004-schema-minor-compatibility.md): `CURRENT_SCHEMA_VERSION = 0.2.0`, yükleme kuralı `major == current && minor <= current`. `0.1.0` projeler yüklenir; `0.3.0` ve `1.0.0` reddedilir; patch uyumluluğu etkilemez.
3. **Kullanıcı kararları.**

   | Konu | Karar |
   | :--- | :--- |
   | Şema/yükleyici | `0.2.0` + `minor <= current` (ADR-0004) |
   | Ses | **Fade-only**: `AudioFadeDef`, per-sample çarpan; keyframe gain automation v1 dışı |
   | Parçacık | **B**: burst alt-yapısı + `emission`; `count`/`seed` statik |
   | Scrim | **1 girişli** `BackdropScrim`; `VectorText` arity'si değişmez |
   | Reframe | **Statik** odak (9:16); kare başına pan yok |
   | Ribbon | **Varsayılan düzeltme**: beyaz karışımı kaldırılır; `min_width_px` ayrı öneri |
   | Autocut | **v1**: hard cut + dry-run; shader geçişi ve `--replace` sonraki dilim |
   | Progress | İlerleme satırları **stderr**'e; stdout sonuç kanalı kalır |
   | Sheet/materials | **Ayrı** `sheet` ve `materials` komutları; `inspect` paketi bölünmez |

4. **P0 streaming encode ölçüldü.** Çalışma kümesi **6.5 GB → 0.27–0.80 GB** (O(N) tampon kaldırıldı; tepe LRU önbelleğiyle sınırlı); tek bir evrensel sayı yok. Fame v3 (720p, 1920 kare): **0.27 GB** / private **0.91 GB** / toplam **100.2 sn**; asta_amv draft (720p): **0.80 GB**; asta_v3 draft (640×360): **0.40 GB**. Baskın terim 128 kare / 1 GiB LRU kaynak önbelleği; 1080p tekrarı ve `render --range` etkileşimi henüz ölçülmedi.
5. **Planlanan uygulama dalgaları.**

   | Dalga | Kapsam | Durum |
   | :--- | :--- | :--- |
   | P0 | Streaming encode; bellek ölçümü | `ölçüldü` |
   | 1 — Şema | ADR-0004 yükleyici, `AudioFadeDef`, `SourceVideo.focus`, parçacık burst alanları, `BackdropScrim`, ribbon alanları | `planlandı` |
   | 2 — Motor | Fade miks, burst/scrim WGSL, ribbon düzeltmesi, statik reframe crop | `planlandı` |
   | 3 — CLI | `render --range`, stderr progress, `sheet`, `materials`, `help`/`--version`, `autocut` v1 | `planlandı` |
   | 4 — Doğrulama | `cargo check`, `cargo test --workspace`, `clippy`, `verify-all`, showcase ve spec senkronu | `planlandı` |
